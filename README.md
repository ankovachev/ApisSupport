# ApisSupport

Система за дистанционна IT поддръжка на „АПИС Европа" АД, изградена като config-driven patch-overlay върху чист RustDesk source.

## Два продукта

- **ApisQuickSupport** — инструмент за клиента (контролиран, само със съгласие).
- **ApisAgent** — инструмент за дилъра/поддръжката (контролиращ, с OTP).

## Принцип

Оригиналният RustDesk source остава непокътнат. Всички промени са `.patch` файлове + JSON конфиг + нови файлове. Rebuild от нова версия на RustDesk — за под 30 минути.

## Легитимност

Безплатен инструмент за поддръжка на собствени клиенти, с тяхно изрично съгласие. Без unattended достъп (забранен by design). Виж `REQUIREMENTS.md`, раздели 0 и 10.
